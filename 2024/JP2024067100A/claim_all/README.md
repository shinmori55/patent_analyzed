前記画像形成装置は、印刷ジョブを実行する毎に、複数の契約条件の従量課金対象の従量の情報を送信する送信手段を有し、
前記情報処理装置は、
画像形成装置から取得した各従量課金対象の従量の情報を所定の期間にわたり累積した累計情報を記憶する記憶手段と、
前記累計情報に基づいて前記複数の契約条件の請求額を算出する算出手段と、
前記複数の契約条件の中から前記請求額のうち最も安価な契約条件を選択する選択手段を
有することを特徴とする印刷課金システム。

を特徴とする請求項１に記載の印刷課金システム。
【請求項3】前記所定の期間は、ジョブ毎、１日毎、１か月毎のいずれかであること
を特徴とする請求項１又は２に記載の印刷課金システム。
【請求項4】前記選択手段は、ユーザの選択した契約条件に固定することが可能である
ことを特徴とする請求項１又は２に記載の印刷課金システム。
